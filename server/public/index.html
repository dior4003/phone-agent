Yangi loyiha yuklash

Git repo manzilidan yuklab, bog'liqliklarni o'rnatib, Node.js (package.json), Python (requirements.txt / main.py) yoki PHP (composer.json / artisan) loyihalarini o'rnatib pm2 ga qo'shasiz.

Private (maxfiy) repo uchun: GitHub'da Settings → Developer settings → Personal access tokens dan token yarating va shu yerga kiriting. Token faqat shu so'rov uchun ishlatiladi, serverda alohida saqlanmaydi.
